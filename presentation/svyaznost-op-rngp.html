Связанность ОП: против бульвара «из ниоткуда в никуда»

Норматив озеленения даёт площадь. Норматив связанности обязан заставить бульвар, сквер и парк работать на повседневные маршруты: дом → сад, магазин, остановка, площадь.

01

Проблема

Бульвар ради м² озеленения без якорей

02

Правило

Линейное ОП засчитывается только с якорями

03

РНГП

Формулировки, которые нельзя обойти площадью

База: СП 42.13330 п. 9.3 (непрерывная система) и п. 9.5 (бульвары по массовым потокам); РНГП операционализирует это расчётными показателями.

Зачем норматив

Типовой обход: бульвар ради озеленения

Как делают сейчас

Озеленение закрыто. По бульвару нельзя отвести ребёнка в сад и сходить в магазин — он не ведёт к якорям.

Как должно быть по связанности

Бульвар соединяет якоря повседневного спроса. Тогда он и даёт м², и работает как маршрут.

Ключ нормы: площадь озеленения ≠ связанность. Бульвар без якорей может закрыть м², но не засчитывается в связанную систему ОП.

Федеральный СП уже говорит «по потокам», но без метрик это не ловит формальный бульвар. РНГП добавляет якоря и запрет засчёта тупикового линейного ОП в связанность.

Определение

Связанность = сеть + повседневный смысл

Мало соединить скверы между собой. Бульвар должен вести к функциональным якорям: ДОУ, магазину, остановке, площади — иначе он не связанность, а декоративное озеленение.

Уровень 1

Физическая

Непрерывный проход: тротуар, аллея, бульвар, переход.

Уровень 2

Функциональная

Путь к якорям повседневного спроса, доступность для МГН.

Уровень 3

Сетевая

ОП + якоря в одной компоненте пешеходного графа.

Функциональные якоря

  • ДОУ / школа, магазин повседневный, остановка
  • Поликлиника / ФАП, досуг местного значения
  • Сквер, сад, парк, площадь

Не засчитывается в связанность

  • Бульвар без якорей на концах / узлах
  • Путь через закрытый двор
  • «Зелень ради м²» вне массовых потоков
  • Переход магистрали вне обустроенного перехода
План · плохо / хорошо

Два сценария планировки района

Разрозненные ОП

Три узла, но разные компоненты связности. Обеспеченность «есть», связанности нет.

Связанная сеть ОП

Узлы + линейные связи (бульвар, променад) + переходы = одна компонента.

Методика проверки

Как проверять связанность на ППТ

  1. Инвентаризация узлов — ОП с площадью, входами, режимом доступа.
  2. Построение рёбер — только пути с тротуаром/аллеей и обустроенным пересечением УДС.
  3. Компонента связности — все нормируемые ОП в одной компоненте.
  4. Изохроны — доля жилья в 400 м по сети до связной сети ОП.
  5. PRD — путь по сети / по прямой ≤ 1,5.

Состав материалов к согласованию

Схема узлов · схема графа с длинами · таблица пар ОП · карта изохрон 5/10 мин · ведомость разрывов.

Измерять по сети пешеходных путей, не по радиусу «по воздуху». Это согласуется с подходом UN-Habitat (service area along street network).

Как мерить 400 м (правильно)

Норма считает путь по тротуарам, не радиус «по воздуху». Изохрона — неровная зона вдоль сети.

Формула отсечения

м² озеленения — сколько зелени.
Связанность — куда по ней пройти.

Закрыл только м² бульваром без ДОУ/магазина/остановки/сквера на концах → связанность не выполнена.

PRD = длина по сети ÷ длина по прямой ≤ 1,5

Критерии ребра сети

Когда путь засчитывается как связь

Засчитывается
  • Непрерывный тротуар / аллея / бульвар
  • Пересечение УДС через переход (в т.ч. регулируемый) или shared space
  • Параметры доступности по СП 59.13330
  • Общедоступность: круглосуточно или по утверждённому регламенту
  • Пешеходная галерея / эспланада общего пользования
Не засчитывается
  • Проезд без тротуара
  • Путь через закрытый двор / частный участок
  • Фактический переход вне зебры через магистраль
  • Лестница без альтернативы для МГН (если сеть нормируемая как доступная)
  • Временный / неоформленный проход

Связь с уже действующим СП

Пункт 9.3 СП 42.13330 уже требует «непрерывную систему озеленённых территорий общего пользования и других открытых пространств». РНГП не создаёт новое понятие с нуля, а операционализирует его расчётными показателями обеспеченности и доступности (формат приказа № 71).

Формулировки для РНГП · часть 1

Термины и область применения

Статья / раздел. Связанность общественных пространств жилых районов 1. Область применения. Показатели связанности применяются дополнительно к нормативам площади озеленения и не подменяются ими: выполнение только норматива площади без связанности не допускается. 2. Термины. ОП — общедоступная территория для пребывания и передвижения (площадь, сквер, сад, парк, бульвар, набережная, пешеходная улица…). Линейное ОП — бульвар, аллея, набережная, променад (связующая функция). Функциональный якорь — объект повседневного тяготения: ДОУ/школа, торговля повседневная, остановка ОТ, первичное здравоохранение, досуг местного значения, иное ОП, вход в общественно-деловую зону. Связанность — нормируемые ОП в одной компоненте пешеходного графа, а линейные ОП обеспечивают связи между функциональными якорями повседневных маршрутов.
Формулировки для РНГП · часть 2

Расчётные показатели

3. Минимально допустимый уровень обеспеченности (связанность). 3.1. 100% нормируемых ОП района — в одной пешеходной компоненте связности. 3.2. Не менее 2 пешеходных подключений системы ОП к смежным планировочным элементам. 3.3. Расстояние по сети между соседними нормируемыми ОП — не более 300 м. 3.4–3.5. Линейные ОП (бульвары). Линейное ОП засчитывается в связанную систему только если: 1) соединяет ≥ 2 функциональных якоря; 2) хотя бы один якорь — объект обслуживания (ДОУ/школа, торговля повседневная, остановка, первичное здравоохранение) либо иное нормируемое ОП; 3) на каждые 400 м длины — вход к якорю или связь к нему; 4) размещено по направлению массовых пешеходных потоков (СП 42 п. 9.5). Бульвар без якорей («из ниоткуда в никуда») не засчитывается в связанность (в м² озеленения — только с отдельной пометкой о невыполнении связанности). 3.6. ≥ 70% длины линейных ОП района — на повседневных маршрутах (дом—сад/школа; дом—магазин; дом—остановка; дом—сквер/площадь).
Формулировки для РНГП · часть 3

Доступность, учёт связей, документы

4. Территориальная доступность. 4.1. ≥ 90% жилой застройки — в ≤ 400 м по сети до ОП связанной системы. 4.2. PRD до ближайшего ОП связанной системы ≤ 1,5. 4.3. Парк планировочного района — ≤ 15 мин (СП 42). 4.4. PRD по повседневным маршрутам дом—ДОУ / магазин / остановка ≤ 1,5 (если объект в районе). 5. Учёт связи. Непрерывность пути; обустроенные пересечения УДС; доступность МГН; без частных дворов; для бульвара — якоря по п. 3.4–3.5. 6. Состав материалов ППТ. Схема ОП (узловые / линейные) · схема якорей и повседневных маршрутов · граф с длинами · расчёт компоненты · ведомость бульваров с якорями и долей «рабочей» длины · изохроны · PRD · ведомость разрывов · экспликация объектов, учтённых в м² озеленения, но не в связанности. 7. Норма развивает СП 42 п. 9.3 и 9.5 и не подменяет норматив площади озеленения.

Итог

Что говорим застройщику

1

м² ≠ связанность

Бульвар может закрыть озеленение и при этом провалить связанность.

2

Нужны якоря

≥2 якоря на линейном ОП: сад/школа, магазин, остановка, сквер, площадь.

3

Проверка в ППТ

Схема повседневных маршрутов + ведомость бульваров с якорями — обязательно.

Рабочая формула нормы

«Линейное ОП засчитывается в связанную систему только если соединяет функциональные якоря повседневного спроса. Иначе — не связанность, даже при выполнении норматива площади озеленения.»
