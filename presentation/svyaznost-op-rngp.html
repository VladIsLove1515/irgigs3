Определение

Что считать связанностью

Связанность — возможность пройти между общественными пространствами по непрерывной, безопасной и общедоступной пешеходной сети без обхода через частные дворы и магистрали без переходов.

Уровень 1

Физическая

Непрерывный проход: тротуар, аллея, бульвар, переход, пешеходная галерея.

Уровень 2

Функциональная

Ширина, уклон, освещение, режим доступа, доступность для МГН (СП 59).

Уровень 3

Сетевая

ОП образуют одну компоненту связности пешеходного графа района.

Узлы сети (ОП)

  • Площади, скверы, сады, парки, бульвары, набережные
  • Пешеходные улицы / променады
  • Только общедоступные территории (не закрытый ЖК)

Не являются связью

  • Визуальный контакт без прохода
  • Путь через частный двор / шлагбаум
  • Переход магистрали вне обустроенного перехода
  • «Зелёный коридор» без права прохода
План · плохо / хорошо

Два сценария планировки района

Разрозненные ОП

Три узла, но разные компоненты связности. Обеспеченность «есть», связанности нет.

Связанная сеть ОП

Узлы + линейные связи (бульвар, променад) + переходы = одна компонента.

Методика проверки

Как проверять связанность на ППТ

  1. Инвентаризация узлов — ОП с площадью, входами, режимом доступа.
  2. Построение рёбер — только пути с тротуаром/аллеей и обустроенным пересечением УДС.
  3. Компонента связности — все нормируемые ОП в одной компоненте.
  4. Изохроны — доля жилья в 400 м по сети до связной сети ОП.
  5. PRD — путь по сети / по прямой ≤ 1,5.

Состав материалов к согласованию

Схема узлов · схема графа с длинами · таблица пар ОП · карта изохрон 5/10 мин · ведомость разрывов.

Измерять по сети пешеходных путей, не по радиусу «по воздуху». Это согласуется с подходом UN-Habitat (service area along street network).

Критерии ребра сети

Когда путь засчитывается как связь

Засчитывается
  • Непрерывный тротуар / аллея / бульвар
  • Пересечение УДС через переход (в т.ч. регулируемый) или shared space
  • Параметры доступности по СП 59.13330
  • Общедоступность: круглосуточно или по утверждённому регламенту
  • Пешеходная галерея / эспланада общего пользования
Не засчитывается
  • Проезд без тротуара
  • Путь через закрытый двор / частный участок
  • Фактический переход вне зебры через магистраль
  • Лестница без альтернативы для МГН (если сеть нормируемая как доступная)
  • Временный / неоформленный проход

Связь с уже действующим СП

Пункт 9.3 СП 42.13330 уже требует «непрерывную систему озеленённых территорий общего пользования и других открытых пространств». РНГП не создаёт новое понятие с нуля, а операционализирует его расчётными показателями обеспеченности и доступности (формат приказа № 71).

Формулировки для РНГП · часть 1

Термины и область применения

Статья / раздел. Связанность общественных пространств жилых районов 1. Область применения. Расчётные показатели настоящего раздела применяются при подготовке документов территориального планирования, документации по планировке территории жилых и общественно-жилых районов (кварталов), а также при оценке обеспеченности населения озеленёнными территориями общего пользования и иными общественными пространствами. 2. Термины. Общественное пространство (ОП) — территория общего пользования либо иная территория с установленным режимом беспрепятственного доступа неограниченного круга лиц, предназначенная для пребывания и передвижения населения (площадь, сквер, сад, парк, бульвар, набережная, пешеходная улица, променад и иные аналогичные территории). Пешеходная связь — непрерывный путь передвижения пешеходов между входами (точками доступа) общественных пространств по элементам пешеходной инфраструктуры, соответствующим требованиям безопасности и доступности. Связанность общественных пространств — состояние системы ОП, при котором нормируемые ОП образуют единую компоненту связности пешеходного графа.
Формулировки для РНГП · часть 2

Расчётные показатели

3. Минимально допустимый уровень обеспеченности (связанность). 3.1. Не менее 100% нормируемых общественных пространств жилого района площадью не менее установленной настоящими нормативами (для сквера — не менее 0,5 га, если иное не установлено для условий реконструкции) должны входить в одну пешеходную компоненту связности. 3.2. Система общественных пространств жилого района должна иметь не менее двух пешеходных подключений к озеленённым территориям общего пользования и (или) пешеходным пространствам смежных планировочных элементов города. 3.3. Максимальное расстояние по пешеходной сети между соседними нормируемыми ОП не должно превышать 300 м. 4. Максимально допустимый уровень территориальной доступности. 4.1. Не менее 90% площади территории жилой застройки района должно находиться в пределах пешеходной доступности не более 400 м по сети пешеходных путей до ближайшего общественного пространства, входящего в связанную систему ОП. 4.2. Коэффициент прямизны пешеходного маршрута от жилой застройки до ближайшего ОП связанной системы (отношение длины пути по сети к расстоянию по прямой) не должен превышать 1,5. 4.3. Для парков планировочных районов время доступности принимается в соответствии с СП 42.13330 (не более 15 минут).
Формулировки для РНГП · часть 3

Правила учёта связей и подтверждение

5. Условия учёта пешеходной связи. Пешеходная связь учитывается при одновременном соблюдении условий: 1) непрерывность пути без разрыва пешеходной инфраструктуры; 2) пересечение проезжей части — только через обустроенный пешеходный переход, внеуличный переход с обеспечением доступности либо участок улицы с приоритетом пешеходов, предусмотренный проектом; 3) соответствие пути требованиям доступности для маломобильных групп населения; 4) отсутствие правовых и физических препятствий общего доступа (закрытые дворы, частные территории, режимные объекты не образуют рёбер сети). 6. Подтверждение соответствия. В составе документации по планировке территории представляются: схема общественных пространств; схема пешеходного графа с длинами связей; расчёт компоненты связности; карта изохрон пешеходной доступности; расчёт коэффициента прямизны; ведомость разрывов и компенсирующих мероприятий. 7. Соотношение с федеральными нормами. Показатели настоящего раздела применяются в развитие требования СП 42.13330 о формировании непрерывной системы озеленённых территорий общего пользования и открытых пространств и не подменяют нормативы площади озеленения и времени доступности парков, установленные сводами правил.

Числа 300 м, 90%, ≥2 выхода — проектные; рекомендуется калибровка на 2–3 пилотных ППТ перед утверждением. 400 м и PRD 1,5 опираются на устойчивую международную и региональную практику.

Итог

Коротко для градсовета

1

Связанность ≠ обеспеченность

«Есть три сквера» недостаточно. Нужна одна пешеходная сеть.

2

Проверка = граф + изохроны

По сети, не по воздуху. Материалы — обязательное приложение к ППТ.

3

РНГП = 2 типа показателей

Обеспеченность связности + макс. доступность (400 м, PRD 1,5).

Рекомендуемый порядок внедрения

1) Утвердить термины и методику расчёта → 2) Пилот на 2–3 ППТ → 3) Закрепить показатели в РНГП → 4) Через мониторинг ужесточить шаг сети / долю покрытия.
