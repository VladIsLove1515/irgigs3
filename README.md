## Как открыть презентацию

Откройте `presentation/svyaznost-op-rngp.html` в браузере. Для печати в PDF: Ctrl/Cmd+P → «Сохранить как PDF».

## Суть нормы

РНГП операционализирует уже существующее требование СП 42.13330 п. 9.3 о **непрерывной системе** озеленённых территорий общего пользования: связанность проверяется через пешеходный граф, изохроны по сети и коэффициент прямизны маршрута.
