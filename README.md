## Суть нормы

РНГП отделяет **площадь озеленения** от **связанности**: бульвар «из ниоткуда в никуда» может закрыть м², но не засчитывается в связанную систему без функциональных якорей (ДОУ, магазин, остановка, сквер/площадь) на повседневных маршрутах. Норма опирается на СП 42.13330 п. 9.3 и 9.5 и делает их проверяемыми.
